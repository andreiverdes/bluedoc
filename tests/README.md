# Tests

Run `python3 -m unittest discover -s tests` from the repo root (Python 3.9+, standard library only; `node` on the `PATH` adds the template-function checks, which are skipped without it). Each test works on copies of `skills/bluedoc/examples/` in a temp folder with its own `BLUEDOC_HOME`, and the server test runs `serve.py run` on a free port, so nothing touches `~/.bluedoc` or a running server. The four suites are `test_golden_examples` (the examples build clean and match `docs/examples/*.html`; regenerate those with `build.py <example> -o docs/examples/<name>.html` after a template change), `test_security` (script-injection probes against `build.validate`, `build.build` and the template's `safeUrl`, `inline` and `num`), `test_server_guards` (path traversal, Host, cross-site POST and `wait` header checks) and `test_key_roundtrip` (every key the annotator's `keyOf` emits on the examples resolves in `build.py patch`, and `SKILL.md` and `references/schema.md` list every key form).
